# Числовые типы данных

При решении задач важно правильно выбрать тип данных. 
Для количества предметов используется целочисленный тип (например, `int` в Python или C++). Он не хранит дробную часть.
Для денег или дробных значений используется тип с плавающей точкой (например, `float` или `double`).
Если перепутать типы, можно потерять точность при вычислениях.
