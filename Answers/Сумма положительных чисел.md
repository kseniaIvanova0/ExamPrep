# Сумма положительных чисел

Дан список целых чисел. Нужно сложить только положительные числа.
Для решения выбираем целочисленный тип для суммы (см. [[Тип данных]]).
Используем [[Логическое выражение]] для проверки: число больше нуля.
Перебираем элементы с помощью [[Цикл]].

Пример: для списка [3, -2, 0, 5] сумма будет 8.
