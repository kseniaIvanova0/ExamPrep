# Подготовка к экзамену по программированию

## Распределение ролей
* **Участник А (Ксения)**: Вопросы 1, 2 (Числовые типы, Списки/Строки) + Словарь.
* **Участник Б (Твой Одногруппник)**: Вопросы 3, 4 (Условия, Циклы).
